MouseRipple（Windows 增强美化版）
==================================

全新升级版本：现已全面重构水波光学渲染架构与设置面板，提供如同专业数位板与原生系统般的通透视觉体验。

核心视觉与渲染特性
------------------
- 💧 立体双层空灵水波（全新重构）：
  - 【彻底消除硬切边】：采用超宽渐进羽化算法（Asymptotic Gaussian Falloff），外边缘平滑融入背景，告别“贴纸切边感”
  - 【全景中空水波环】：中心完全中空通透，绝不形成实心色饼，光标与被点击内容清晰可见
  - 【光学双层阴阳对比】：底层引入超微弱炭灰折射阴影（Ambient Shadow），在纯白、中性灰（ Neutral Gray #C8CCD0 ）、深色全背景下均清晰饱满且通透立体
- ⭕ 常驻单圈纯净线条呼吸圈：
  - 单圈从容呼吸循环，绝不密集喧闹
  - 纯线条呈现，支持 1~6px 粗细无级调节
  - 支持 0%~100% 透明度调节与任意自选颜色，默认温和跟随指针
- ✨ 经典 Wacom 触控笔与水波风格自由切换：
  - 响应轻快细腻，具备真实的落点微反馈与柔和退散效果
  - 支持 1~3 圈同心波纹扩散，演示录屏清晰醒目
- 🛠️ 现代化可视化设置面板：
  - 预设一键切换（Wacom 极简 / 立体水波 / 自定义）
  - 左键、右键、中键颜色与常驻水波颜色各自独立自选
  - 最大半径、扩散时长、线条粗细、波纹圈数、不透明度、常驻半径/粗细/透明度全部滑块实时微调
  - 界面打开时任务栏自动置顶显示，双击托盘图标或再次双击 exe 均可直达设置面板
- ⚙️ 参数自动保存：所有配置即时持久化到同目录 `MouseRipple.ini`
- 🚀 系统托盘与自启动：
  - 托盘右键菜单支持【设置】、【开机自启动】、【退出】

编译与运行
----------
一键编译：
直接双击运行 `build.bat` 即可（会自动寻找 Visual Studio 环境并编译输出 `MouseRipple.exe`）。

命令行手动编译：
cl /nologo /EHsc /O2 /std:c++17 /DUNICODE /D_UNICODE MouseRipple.cpp /link /SUBSYSTEM:WINDOWS gdiplus.lib user32.lib gdi32.lib shell32.lib comctl32.lib comdlg32.lib advapi32.lib /OUT:MouseRipple.exe

技术说明
--------
- 纯 C++17 + 原生 Win32 API + GDI+ 硬件加速级渲染
- 零第三方依赖，极致轻量 (~15MB 内存)
- `WH_MOUSE_LL` 全局低延迟鼠标钩子
- `WS_EX_LAYERED` + `WS_EX_TRANSPARENT` 全虚拟屏幕穿透，绝不拦截任何鼠标点击
